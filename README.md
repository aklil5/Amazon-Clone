# Amazon-Clone
A full-stack e-commerce web application inspired by Amazon, built to practice modern web development. Users can browse products, search and filter by category, view product details, manage a shopping cart, and check out.

## Tech Stack
- Frontend: React and Vite
- Backend: Node.js (Express)
- Database: MySQL (for products, users, carts, and orders)

## Features
- Product listing and detail pages
- Search and category filtering
- Shopping cart and checkout flow
- User authentication (sign up and login)
- Order history

## Getting Started
1. Clone the repository
2. Install dependencies with npm install
3. Start the development server with npm run dev
